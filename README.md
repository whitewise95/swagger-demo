# swagger demo
> swagger(openApi) template로 사용할 demo 입니다.


# spec
- Java 17
- Spring boot 3.4.1
- Gradle 8.11.1
- Springdoc OpenAPI 2.2.0

# start
1. **프로젝트 클론 (Clone)**
   먼저, 프로젝트를 로컬 환경에 복제합니다:
   ```bash
   git clone https://github.com/your-repository/swagger-demo.git
   cd swagger-demo
   ```
2. **스웨거 접속**
   어플리케이션 Run 이후 스웨거에 접속합니다:
   ```bash
    http://localhost:8080/swagger-ui.html
   ```
